# CUBIT — documentation

Source of https://gitbook.cubit.fund, built with HonKit, in ten languages. `docs/` holds the French source pages;
`translations/` and `i18n/` hold the other nine languages.

```bash
npm install
npm run build     # builds every language into _book/
npm run check     # checks pages, links and languages
npm run preview   # serves the build locally
```
