# 买入与卖出

Dapp 通过所选部署的路由器提供 ETH/CUBIT 交换。税在 hook 中征收；预计接收金额应已扣除报价包含的税。

> 连接 Ethereum 的 dapp 使用 **LP 费用 0.01 %** 的当前版本，并读取该版本的 ABI。市场开放之前无法交易。演示或模拟模式不代表链上状态。

## 准备交换之前

确认钱包网络、显示的部署和数据区块。交换额之外另备 ETH 支付 gas。Dapp 应提示 RPC 不可用或数据过期，并阻止基于未核实状态的签名。

账户、网络、金额或路由器地址变更后需重新报价。外围地址可经 V2 注册表变更。

## 买入 CUBIT

1. 选择 ETH 金额。固定输入时，3 % 买入税已包含其中。
2. 查看预计净得 CUBIT、费用及滑点容忍度规定的最低接收量。
3. 核查模拟和钱包显示的详细信息，然后签名。
4. 等待成功回执和链上余额刷新。

买入通过 `msg.value` 使用原生 ETH。CUBIT 路由器此路径不用 Permit2。在新版本中，买入会沿流动性带的 x·y=k 曲线从中取出 CUBIT。

## 卖出 CUBIT

卖出可能需要 **ERC-20 授权（approval）**，允许路由器转移所选数量的 CUBIT。前端准备的授权额度为请求金额。

授权确认后，dapp 在交换前重新核查账户、网络、注册表修订号和报价新鲜度。原授权不足时，授权与卖出是两笔独立交易。

卖出返回扣除 15 % 税后的 ETH：毛额的 12 % 用于买墙，3 % 归团队。在新版本中，卖出会清空其完全穿越的买墙，并将待配置的 ETH 放入一个买墙；随后 CUBIT 路由器将被吸收的 CUBIT 发送至 vault 储备。

## 最低接收量与截止时间

**滑点**限定相对报价可接受的偏差。税已包含在报价中，不应据此随意增加 15 个百分点滑点。

已读前端源码中，报价 **30 秒**内有效。交易截止时间以链上时间戳计算。授权等待过久可能导致无法签名，此时需重新查看最新报价。

限制条件拒绝交易，是在保护约定的最小或最大金额。失败并不意味着应该移除限制。

## 交易未通过时

| 情况 | 有用操作 |
| --- | --- |
| 网络错误或账户变更 | 恢复所需上下文并重新报价 |
| 报价过期 | 重算净额与最低接收量 |
| 路由器或修订号变更 | 核查当前地址与新操作；旧授权仍属于旧 spender |
| 流动性不足 | 对较小金额报价，并检查现有仓位 |
| 卖出穿越大量买墙 | 拆分卖出：穿越超过约 88 个买墙时，会超出单笔交易的 gas 上限 |
| RPC 不可用 | 等待有效链上读取后再签名 |
| 已发送交易 | 准备下一笔前先核查 hash 和回执 |

路由器拒绝未完全消耗的输入或未完全满足的固定输出。回滚交易花费的资金由 EVM 撤销，但 gas 除外。

## 核查结果

Hash 表示交易已提交，只有回执说明是否成功。检查浏览器网络、状态、接收方及 `BuyTaxed` 或 `SellTaxed` 事件。

买墙参考价格不能替代具体订单的报价。[读取 dapp 数据](preuves.md)。
