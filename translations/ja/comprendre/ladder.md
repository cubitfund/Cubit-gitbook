# 流動性バンド

CUBIT の取引用流動性は、TIDE モデルに倣った**単一の広いバンド**に収められています。フックはローンチ時にこのバンドを置き、決して引き出しません。これが旧来のラダーに代わります。

## バンドの中身

| パラメーター | 採用値 |
| --- | --- |
| 預入れ | 供給量の 80 %、すなわち 1,680万 CUBIT |
| ローンチ時の構成 | 100 % CUBIT、ETH なし |
| 価格範囲 | ローンチ価格より上のすべての価格 |
| ローンチ時 FDV | 3.75 ETH、つまりバンドの厚みは 3 ETH |
| 引出し | なし：ポジションが引き出されることはない |

バンドの下限は tick に丸めたローンチ価格に対応するため、ポジションは開始時に ETH を一切含みません。その上では、プールの価格曲線全体をカバーします。

## x·y=k 曲線

購入と売却はバンドの定積曲線に従います。購入はバンドに ETH を入れて CUBIT を取り出すため、価格が上がります。売却はその逆で、価格が下がります。

ローンチ時 FDV が 3.75 ETH の場合、1,680万 CUBIT は**ローンチ価格で 3 ETH** に相当します。開始時のバンドは、1,680万 CUBIT と 3 ETH からなる x·y=k プールのように振る舞います。この 3 ETH は**仮想**のもので、曲線の傾きを決めますが、バンドが実際に保有するのは購入者が持ち込んだ ETH だけです。

## バンドが保証しないもの

売り手がバンドから引き出せる ETH は、購入者がバンドに入れた ETH です。価格がローンチ価格に戻るとバンドには CUBIT しか残らず、その価格より下では CUBIT を買い戻せません。

したがって、ローンチ価格より下での売却は、買い壁にまだ残っている ETH によってのみ約定できます。3 ETH の厚みは、プロトコルが預け入れた ETH の準備金でも、最低価格でもありません。

## ラダーとともに廃止されたもの

バンドは旧来の移動式オーダーブックに代わるものです。次のものが廃止されました：

- ラダー、その連続する帯とトークン準備分
- ETH のクッション（cushion）
- `rebalance`、`raiseFloor`、買い壁への sweep、keeper 報奨金

市場を動かすためのメンテナンス呼出しは不要です。keeper はもう存在しません。

## Forge の子市場のバンド

Forge で作成された子市場も同じモデルに従いますが、一つ違いがあります。**供給量の 100 % を自身のバンドに預け入れる**点です。Vault の準備金もチームへの割当てもありません。フックは供給量の 80 % 以上の預入れを要求し、預入れの全額をバンドに配置します。[Momentum と Forge](../v2/momentum-forge.md)。

## バンドを確認する

フックの `band()` ビューはポジションの tick と流動性を返し、`BandBootstrapped` イベントはローンチ時に発行されます。Lens は、現在価格でバンドが保有する ETH と CUBIT を、LP 手数料を除いて `bandEth` と `bandTokens` として公開します。[コントラクトと連携](../developper/integration.md)。
