# 用語集

| 用語 | CUBIT での定義 |
| --- | --- |
| ABI | コントラクト通信に必要な関数・イベント・型の記述 |
| デプロイヤー購入 | ローンチのトランザクションに含まれる 0.1 ETH の購入。3 % が課税され、ロックされない |
| チームアドレス | チーム分の税を受け取り、レジストリのモジュールをいつでも遅延なく交換してから有効化できる固定アドレス。その権限は恒久的 |
| Approval（承認） | spender アドレスに数量を指定した ERC-20 許可 |
| バンド | ローンチ時に供給量の 80 % で置かれる単一の取引用ポジション。ローンチ価格より上のすべての価格をカバーし、引き出されない |
| Burn（バーン） | トークンの破棄。新バージョンでは買い壁の CUBIT をバーンせず、ローンチ時の丸めによる端数だけをバーンする |
| 目標 | 買い壁を置くために売却ごとに売却後の価格で計算する水準：0.4 × 現在価格 + 0.6 × ローンチ価格。ローンチ価格以下では買い壁を現在価格の 1 % 下に配置 |
| ERC-6909 claim | PoolManager で保有する決済・資産保持用の会計単位 |
| 報酬 claim | 獲得報酬を請求する呼出し。ERC-6909 claim とは別の意味 |
| x·y=k 曲線 | バンド内の購入と売却が従う定積曲線 |
| 保有 CUBIT | 流通供給量から、バンドがまだ売っていない CUBIT を差し引いた量。ステークされた CUBIT を含め、ホルダーが持つ量 |
| Deadline（期限） | 操作・署名を受け付ける最大 timestamp |
| Exact-input | 入力固定、出力を最小値で保護するスワップ |
| Exact-output | 出力固定、入力を最大値で保護するスワップ |
| ローンチ時 FDV | ローンチ価格を決める完全希薄化時価総額。新バージョンでは 3.75 ETH を採用 |
| LP 手数料 | フック税とは別のプール手数料 |
| Floor | コードで使われる過去の名称。買い壁と目標は別々に読む |
| Hook | Uniswap v4 操作に接続し CUBIT の仕組みを適用するコントラクト。管理者はいない |
| Idle ETH | いずれのポジションにも属さずに計上される ETH。区分を明示する |
| Lens | hook とプールから値を導く読取りコントラクト |
| 流動性 / 厚み | 状態と価格に応じたポジション内の実際に使える資産 |
| 最良の買い壁 | 市場に最も近い有効な買い壁で、売却が最初に当たるもの。Lens はその総額価格と、手数料と税を差し引いた価格を返す |
| 買い壁 | 売却によって ETH で資金供給される、tick が固定された LP ポジション。tick ごとに買い壁は一つ |
| 一部消費された買い壁 | ETH の一部が CUBIT を買い戻した買い壁。その場にとどまる |
| 通過された買い壁 | 売却によって完全に CUBIT へ転換された買い壁。通過した売却がそれを空にし、Vault の準備金に回す |
| 流通供給量 | 総供給量から、買い壁の CUBIT、送付待ちの CUBIT、登録済みのすべての Vault の報酬準備金を差し引いた量。ステークされた CUBIT は流通に含まれる |
| Pending absorbed tokens | 通過された買い壁の CUBIT。`deliverAbsorbed()` で送られるまでフック内に分離して保持 |
| Pending floor ETH | 配置待ちの買い壁の資金：売却の 12 % と通過された買い壁から解放された ETH で、同じ売却が配置する。残るのはポジションを作るには小さすぎる端数と、価格が tick 範囲の最上端にある極端な場合だけ |
| Permissionless（許可不要） | 誰でも呼出し可能、コントラクトの決定的条件に従う |
| PoolId | PoolKey 全体から導く識別子 |
| ローンチ価格 | デプロイ時に固定される CUBIT 当たりの ETH 価格：ローンチ時 FDV を 2,100万で割った値 |
| V2 レジストリ | 現行モジュール、改訂、公開中の機能、Vault の履歴を保持するコントラクト |
| 報酬準備金 | 預入者への支払いのために Vault が保有する CUBIT：ローンチ時に供給量の 20 %、その後は通過された買い壁の CUBIT |
| Slippage（スリッページ） | 見積もりから許容する約定差。スワップ制限で制約 |
| Snapshot（スナップショット） | 指定ブロックで読んだ整合するデータ集合 |
| Tick | プール価格の離散単位。ETH/CUBIT 価格と向きが逆 |
| V1 / V2 | 市場中核 / ロードマップの追加機能 |
| ガバナンス Vault | Forge のローンチ手数料（ETH、ローンチした側に返金されない）と、Forge の子市場の買い壁のトークンを受け取るローンチパッドの Vault。各預入れは 30 日間、延長があればその分も加えてロックされ、その後はデプロイヤーだけが請求でき、この権利は恒久的で譲渡不可。デプロイヤーはロックを延長できるが、短縮はできない |

単位とコントラクトメソッドは[連携](developper/integration.md)を参照してください。
