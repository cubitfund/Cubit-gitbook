# 용어집

| 용어 | CUBIT의 정의 |
| --- | --- |
| ABI | 컨트랙트와 통신하기 위한 함수·이벤트·타입 설명 |
| 배포자 매수 | 출시 트랜잭션에 포함된 0.1 ETH 매수, 3 % 과세되며 잠기지 않음 |
| 팀 주소 | 세금의 팀 몫을 받고 레지스트리 모듈을 언제든 지체 없이 교체한 뒤 활성화할 수 있는 고정 주소, 그 권한은 영구적 |
| Approval(승인) | spender 주소에 금액별로 주는 ERC-20 허용 |
| 밴드 | 출시 때 공급량의 80 %로 배치하는 단일 거래 포지션, 출시 가격보다 높은 모든 가격을 포괄하며 회수되지 않음 |
| Burn(소각) | 토큰 파기. 새 버전은 매수벽의 CUBIT을 더 이상 소각하지 않고 출시 때의 반올림 잔량만 소각 |
| 목표 | 매수벽을 배치하려고 매도마다 매도 후 가격으로 계산하는 가격대: 0.4 × 현재 가격 + 0.6 × 출시 가격, 출시 가격 이하에서는 매수벽을 현재 가격보다 1 % 낮은 곳에 배치 |
| ERC-6909 claim | 자산 정산·보유를 위해 PoolManager에서 보유한 회계 단위 |
| 보상 claim | 쌓인 보상을 청구하는 호출, ERC-6909 claim과 다른 용례 |
| x·y=k 곡선 | 밴드에서 매수와 매도가 따르는 상수곱 곡선 |
| 보유 CUBIT | 유통 공급량에서 밴드가 아직 팔지 않은 CUBIT을 뺀 양, 스테이킹된 CUBIT을 포함해 보유자가 가진 양 |
| Deadline(기한) | 작업·서명에 허용되는 최대 timestamp |
| Exact-input | 입력 고정, 출력은 최소값으로 보호하는 스왑 |
| Exact-output | 출력 고정, 입력은 최대값으로 보호하는 스왑 |
| 출시 FDV | 출시 가격을 정하는 완전 희석 시가총액, 새 버전은 3.75 ETH 채택 |
| LP 수수료 | hook 세금과 별개인 풀 수수료 |
| Floor | 코드에 쓰이는 과거 이름, 매수벽과 목표는 따로 읽어야 함 |
| Hook | Uniswap v4 작업에 연결되어 여기서는 CUBIT 동작을 적용하는 컨트랙트, 관리자가 없음 |
| Idle ETH | 어떤 포지션에도 속하지 않은 채 회계에 기록된 ETH, 구획 명시 필요 |
| Lens | hook·풀에서 수치를 도출하는 읽기 컨트랙트 |
| 유동성 / 깊이 | 상태·가격에 따라 포지션에서 실제 사용 가능한 자산 |
| 최선 매수벽 | 시장에 가장 가까운 활성 매수벽으로 매도가 처음 만나는 벽, Lens는 그 총가격과 수수료·세금을 뺀 순가격을 제공 |
| 매수벽 | 매도로 ETH 자금을 조달하는 고정 tick의 LP 포지션, tick마다 매수벽 하나 |
| 일부 소모된 매수벽 | ETH 일부로 CUBIT을 매입한 매수벽, 그 자리에 남음 |
| 통과된 매수벽 | 매도로 전부 CUBIT으로 바뀐 매수벽, 그 매수벽을 통과한 매도가 비우며 그 CUBIT은 vault 준비금으로 감 |
| 유통 공급량 | 총공급량에서 매수벽의 CUBIT, 전송 대기 중인 CUBIT, 등록된 모든 vault의 보상 준비금을 뺀 양이며, 스테이킹된 CUBIT은 유통량에 남음 |
| Pending absorbed tokens | 통과된 매수벽의 CUBIT, `deliverAbsorbed()`로 전송될 때까지 hook 안에 격리됨 |
| Pending floor ETH | 배치를 기다리는 매수벽 자금: 매도의 12 %와 통과된 매수벽에서 풀려난 ETH로, 같은 매도가 배치함. 포지션을 만들기에 너무 작은 미세 잔량과 가격이 tick 범위의 맨 위에 있는 극단적인 경우만 남음 |
| Permissionless(무허가) | 누구나 호출 가능, 컨트랙트의 결정적 조건 적용 |
| PoolId | 전체 PoolKey에서 도출한 식별자 |
| 출시 가격 | 배포 때 고정되는 CUBIT당 ETH 가격: 출시 FDV를 2,100만으로 나눈 값 |
| V2 레지스트리 | 현재 모듈·개정·열린 기능·vault 기록을 보존하는 컨트랙트 |
| 보상 준비금 | 예치자에게 지급하려고 vault가 보유한 CUBIT: 출시 때 공급량의 20 %, 이후 통과된 매수벽의 CUBIT |
| Slippage(슬리피지) | 견적 대비 허용 체결 차이, 스왑 한도로 제한 |
| Snapshot(스냅샷) | 특정 블록에서 읽은 일관된 데이터 집합 |
| Tick | 풀 가격의 이산 단위, ETH/CUBIT 가격과 방향이 반대 |
| V1 / V2 | 시장 핵심 / 로드맵 추가 기능 |
| 거버넌스 vault | Forge 출시 수수료(ETH, 출시자에게 환불되지 않음)와 Forge 자식 시장 매수벽의 토큰을 받는 런치패드 vault, 각 예치분은 30일간, 연장이 있으면 그만큼 더 잠기며 그 뒤 배포자만 청구 가능, 이 권리는 영구적이고 양도 불가, 배포자는 잠금을 연장할 수 있으나 줄일 수 없음 |

단위·컨트랙트 메서드는 [통합](developper/integration.md)을 보세요.
